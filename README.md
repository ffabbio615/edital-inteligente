# Edital Inteligente

Plataforma que identifica, organiza, analisa e recomenda oportunidades públicas e privadas disponíveis no Brasil (editais de fomento, financiamentos, bolsas, aceleração, premiações e chamadas públicas).

## Partes do projeto

| Parte | Tecnologias | Status |
| --- | --- | --- |
| `backend/` | Node.js, TypeScript, Express, PostgreSQL | **Etapa 1: estrutura inicial** |
| Frontend | React, TypeScript, Vite, Sass | Planejado |
| Automação e IA | n8n, Gemini Flash Lite | Planejado |

Consulte [`backend/README.md`](backend/README.md) para instalar e executar o backend.
